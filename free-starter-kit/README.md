# Drafted by AI. Done by you. The starter kit

Free, from The Agentic Data Engineer. For data engineers who build with an AI coding assistant
(Claude Code, Codex or similar) and want to stay the one who decides.

**The rule behind everything in this kit:** AI drafts. You decide. No phase is complete without your
sign-off.

## What's inside

| File | What it gives you | Time to use |
| --- | --- | --- |
| [one-rule-checklist.md](one-rule-checklist.md) | One page: the five phases, and the questions you answer before signing each one off | Print it |
| [starter-prompts.md](starter-prompts.md) | Five prompts, one per phase, that make the AI stop at your gates | Copy and paste |
| [skills/answer-key-first/](skills/answer-key-first/) | A skill for your AI assistant: write the right answers before any code exists | One folder to copy |
| [worked-example.md](worked-example.md) | The real build behind the videos, in one page: what review caught | Read once |

## Start here

1. Read the checklist.
2. Copy the `answer-key-first` folder into your project's `.claude/skills/`.
3. Paste the requirements prompt from `starter-prompts.md` with your own business problem.
4. Don't let the AI start design until you've approved the answer key.

## What this kit is not

A demo of a method, built on synthetic data. It is not production guidance, a benchmark, or a
replacement for your team's reviews: security, subject matter experts and business users are still yours
to involve.
