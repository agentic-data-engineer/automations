# Claims recovery workbench

The first build: a tool on Databricks that finds denied and underpaid hospital claims and shows the
evidence behind each one, taken from requirements to a dry run. All data is synthetic: no real patients,
payers or money. This is a look at what the tool can do. It is not a benchmark, and it is not a
replacement for a team.
