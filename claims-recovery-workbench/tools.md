# What was used

Nothing here is sponsored.

## The build

| Tool | What it did |
| --- | --- |
| Claude Code (Anthropic) | The AI that built it: wrote requirements drafts, design, pipelines, tests and checks, directed by Erum's prompts |
| Codex (OpenAI) | Second AI, used only as an independent reviewer. Found 5 issues; all resolved |
| Databricks | The platform: Unity Catalog, Spark Declarative Pipelines (bronze, silver, gold), a serverless SQL warehouse, an AI/BI dashboard |
| Git | Every phase committed; the expected answers were locked in git before any code existed |
| A delivery checklist (a Claude Code "skill") | Erum's delivery checklist and approval gates for each phase, so every phase stopped for her decision |
| A build log | Records every prompt and tool call automatically; the source of the prompt pack |
